# 6. 土木技術

# 6.1 堤防

## FACT-T01

### 技術

堤防

### 何を防ぐ / 改善する技術か

河川の水が堤内地へ流れ込むことを防ぎ、計画高水位以下の流水を安全に流下させることを目的とする施設。

### 向いている状況

河川沿いで、

* 堤防が存在しない区間
* 堤防高が不足している区間
* 堤防幅が不足している区間

等の治水対策として整備される。

阿武隈川河川整備でもこのような区間が整備対象になっている。

### 限界・注意点

堤防は万能ではない。

国土交通省資料では、

* 越水
* 洗掘
* 漏水
* 亀裂

等が破堤につながる要因として扱われている。

### NPC が避けるべき誤解

「堤防があればどのような洪水でも安全」

とは説明しない。

### 出典

国土交通省「堤防」

破堤等に関する資料:

https://www.mlit.go.jp/river/pamphlet_jirei/kasen/jiten/yougo/09.htm

### 信頼度

A

# 6.3 遊水地・調節池

## FACT-T03

### 技術

遊水地 / 調節池

### 何を防ぐ / 改善する技術か

洪水時の水を一時的に貯留し、下流へ流れる洪水のピーク流量を低減する。

### 向いている状況

下流へ一度に大量の洪水流が流れることを抑制したい場合。

### 阿武隈川流域の実例

浜尾遊水地。

所在地は須賀川市。

洪水時に阿武隈川の水の一部を遊水地へ流入させ、下流の流量・水位を低減する施設として説明されている。

### 限界・注意点

浜尾遊水地は阿武隈川流域の実在事例だが、郡山市内の施設ではない。

### NPC が避けるべき誤解

* 浜尾遊水地を郡山市の施設として説明しない。
* ゲーム内に同様の施設を配置しても、実在の浜尾遊水地と同一施設として扱わない。
* 遊水地だけですべての洪水を防げると説明しない。

### 出典

国土交通省「遊水地・調節池」

# 6.4 排水機場・排水ポンプ

## FACT-T04

### 技術

排水機場 / 排水ポンプ

### 何を防ぐ / 改善する技術か

洪水時に本川の水位が高くなり、支川や市街地の雨水を自然に河川へ排水できなくなった場合に、ポンプで水を河川へ排出する。

主に内水被害の軽減に使用される。

### 向いている状況

本川の水位上昇により、

* 樋門
* 樋管

等を閉鎖しなければならず、堤内地の雨水を自然排水できなくなる状況。

### 郡山市の実例

過去の国土交通省記録では、

* 愛宕川排水機場
* 舘下排水機場

の稼働が確認できる。

### 限界・注意点

機械設備であるため、

* ポンプ能力
* 設備の信頼性
* 維持管理
* 故障
* 運転条件

等の制約がある。

### NPC が避けるべき誤解

「排水ポンプを設置すれば内水氾濫は絶対に起きない」

とは説明しない。

# 6.5 河道掘削・河道整備

## FACT-T05

### 技術

河道掘削 / 河道整備

### 何を防ぐ / 改善する技術か

河道断面を確保し、洪水を流す能力を確保・向上させる。

阿武隈川の河川整備でも、河道断面が不足する区間について河道掘削が行われている。

### 向いている状況

河道内の土砂堆積などにより、洪水を流すために必要な河道断面が不足している場合。

### 限界・注意点

国土交通省資料では、流下能力を増加させる場合、河道拡幅を基本としつつ検討する考え方が示されている。

河床を安易に掘り下げると、

* 水深増加
* 流速増加
* 掃流力増加
* 河床低下
* 護岸への影響

等が起こる可能性がある。

### NPC が避けるべき誤解

「川底を深く掘れば掘るほど安全」

とは説明しない。

### 出典

阿武隈川河川整備:

https://www.thr.mlit.go.jp/fukushima/kasen_seibi/1_3.html

国土交通省 河道計画資料:

https://www.mlit.go.jp/river/bousai/hukkyu/shinsei/4/kadou_02.html

### 信頼度

A

## FACT-D02

### 分類

避難行動

### NPC が扱えるテーマ

「いつ避難すればよいのか」

### 確認できた事実

内閣府の避難情報ガイドラインでは、警戒レベルを用いて避難行動が整理されている。

基本的な考え方として、

* 警戒レベル3：高齢者等避難
* 警戒レベル4：避難指示
* 警戒レベル5：緊急安全確保

とされている。

危険な場所にいる住民は、警戒レベル5を待つのではなく、警戒レベル4までに避難することが求められている。

### NPC が避けるべき誤解

以下の説明は禁止。

* レベル5になってから避難を開始すればよい。
* 避難指示が出るまで何もしなくてよい。
* NPC が現実の特定避難経路の安全を保証する。

### NPC Level 利用候補

#### Level 1

危険な場所では警戒レベル4までに避難する。

#### Level 2

高齢者など避難に時間がかかる人は警戒レベル3から避難する。

#### Level 3

* 立退き避難
* 屋内安全確保
* 緊急安全確保

等の違いを扱う。

### 出典

機関：内閣府

資料名：避難情報に関するガイドライン

https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/

### 信頼度

A

# 11. CivilCraft 実装上の基本思想

CivilCraft における治水は、一つの施設によってすべてを解決するものとして扱わない。

国土交通省の流域治水の考え方と同様に、

* 河川で洪水を流す
* 洪水を一時的に貯める
* 内水を排水する
* 河岸を守る
* 土地利用を考える
* 危険な場所から避難する

など、異なる役割を持つ対策を組み合わせる。

NPC は「正解を教える存在」ではなく、

* 地域の過去
* 地形
* 洪水の仕組み
* 土木施設の役割
* 土木施設の限界
* 防災上の判断材料

をプレイヤーへ提供する役割とする。

# 12. Codex への実装指示

Codex は NPC 機能を実装する際、この文書を一次資料 Research の Source of Truth として扱うこと。

実装時には、

1. この文書に存在する Fact ID を可能な限り保持する
2. NPC Knowledge と出典の対応関係を失わない
3. 地域固有情報と一般論を分離する
4. 信頼度 C を確定知識として使用しない
5. 根拠のない情報を補完しない
6. 土木施設を唯一解として扱わない
7. 現実の防災情報とゲーム内シミュレーション状態を混同しない

こと。

推奨する内部データ構造例：

```text
fact_id
category
area
period
topic
fact
limitations
npc_level
source_agency
source_title
source_year
source_page
source_url
confidence
```

この Research 文書から NPC 会話データを生成する場合も、元の Fact ID を参照できる構造を維持すること。
