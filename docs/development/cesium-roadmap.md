# CesiumJS 導入ロードマップ

CesiumJSと国土地理院データを用いたクライアント実装に必要な作業を、依存関係順に整理する。

## 1. データと利用条件の確定

- [ ] 日本大学工学部周辺の対象範囲をポリゴンまたは矩形で確定する
- [ ] 初期カメラの経度・緯度・高度・向きを決める
- [ ] 使用する地理院タイルの種類、ズーム範囲、出典表記を決める
- [ ] 表示用地形と計算用標高のデータソースを決める
- [ ] 標高データの加工・保存・配信方法を決める
- [ ] 実在地域とゲーム上の簡略化に関する注意表示を決める

成果物: マップmetadata、利用データ一覧、出典表示仕様。

## 2. CesiumJS 技術検証

- [x] `apps/web`へCesiumJSを追加する
- [x] ViteでCesiumのWorker、Widget、Assetsを配信できるようにする
- [x] 地理院標準地図をImagery Layerとして表示する
- [x] 地理院の全国最新写真（シームレス）と標準地図を切り替える
- [x] 対象地域へ初期カメラを移動する
- [x] 斜め視点、回転・傾斜操作、影を有効にする
- [x] 初期視点を対象地域へ寄せ、ズーム範囲を制限する
- [x] カメラの注視点を阿武隈川周辺へ制限する
- [x] 地表ピック／ドロップから経度・緯度・標高を取得する
- [x] 仮の施設を1件描画する
- [x] 5種類の施設を立体形状として描画する
- [ ] iOS SafariとAndroid Chromeの実機でFPS、メモリ、読込時間を測る

成果物: スマートフォンで対象地域を表示し、ドックからドラッグ配置できるプロトタイプ。

## 2.5 リアル3D地理空間

- [ ] 国土地理院DEMの対象タイル・解像度・取得日を確定する
- [x] 国土地理院標高PNGをブラウザ内でHeightmap Terrainへ変換する
- [x] Terrain上の地表交点へ施設を配置する
- [ ] 変換済みTerrainをローカルおよびCDNから配信する
- [x] PLATEAU公式全国LOD1 3D Tilesを視点周辺へストリーミングする
- [x] 建物3DレイヤーのON/OFFと読込失敗表示を追加する
- [ ] 郡山市PLATEAUから対象範囲の建物データを抽出する
- [ ] 建物を3D Tilesへ変換し、LOD別の性能を比較する
- [ ] 建物、Terrain、航空写真の高さ・位置ずれを実測する
- [x] 施設5種を用途別の複合基本形状で描き分ける
- [ ] 施設ごとの専用glTFモデルとLODモデルを用意する
- [ ] 洪水水面、浸水深、降雨、工事中表現を追加する

成果物: 航空写真、実地形、周辺建物、土木施設が同じ座標上で表示される対象地域限定の3Dシーン。

## 3. スキーマとマスターデータの移行

- [ ] `Position { x, y, z }`を用途別に地理座標型とローカル計算座標型へ分ける
- [x] 施設配置WebSocket payloadを地理座標対応にする
- [ ] `maps/koriyama/metadata.json`へ境界、カメラ、データ出典を定義する
- [ ] 河川、地形分類、配置可能領域の形式を決める
- [ ] JSON SchemaまたはTypeScript型とデータ検証を追加する
- [ ] 座標範囲と対象地域内判定のテストを追加する

成果物: web/server間で曖昧さなく位置を交換できるスキーマ。

## 4. サーバー権威の施設配置

- [x] 配置候補と確定施設をUI上で区別する（#96: 仮配置プレビュー → 確定／キャンセル）
- [ ] サーバーに対象範囲・地形・重複・予算判定を実装する
- [ ] 成功・失敗レスポンスと失敗理由を定義する
- [ ] 確定した施設をWebSocketで同期する
- [ ] 再描画時もサーバーの施設IDを使用する

成果物: 1人が実在地図上へ施設を配置し、サーバー判定後に確定できる縦切り機能。

## 5. 計算用地形と浸水

- [ ] 対象地域の標高を簡略グリッドへ変換するツールを作成する
- [ ] 河川セル、保護対象セル、配置可能セルを定義する
- [ ] 地理座標とグリッド座標の変換を実装する
- [ ] 水位上昇・越水・浸水判定を決定論的に実装する
- [ ] 浸水結果を地理座標ポリゴンまたはセルとしてクライアントへ配信する
- [ ] CesiumJS上で浸水範囲を軽量に描画する

成果物: 同じ入力で再現可能な簡易洪水シミュレーション。

## 6. MVP統合と運用

- [ ] ルーム、フェーズ、予算、建設時間とCesium画面を統合する
- [ ] タイル・地形取得失敗時の表示とリトライを実装する
- [ ] 出典と免責表示を全画面フローへ組み込む
- [ ] 外部タイルへのアクセス量、CORS、キャッシュを検証する
- [ ] 低性能端末向け描画品質設定を用意する
- [ ] E2Eテストと対象端末の性能基準を定義する

## 完了条件

CesiumJSを表示できるだけでは導入完了としない。対象端末で、対象地域の表示、地表位置取得、サーバー判定付き施設配置、出典表示が動作し、表示用データとゲーム判定の責務が分離されていることを完了条件とする。
