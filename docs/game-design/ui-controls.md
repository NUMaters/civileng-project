# 操作・UI

スマートフォン向けの入力操作と UI フローを定義する。対応環境は [overview.md](./overview.md#対応環境) を参照。

---

## 対応デバイス

MVP では **スマートフォンのタップ操作のみ** を想定する。

タブレット・PC ブラウザでの表示は将来対応とし、MVP では最適化しない。
