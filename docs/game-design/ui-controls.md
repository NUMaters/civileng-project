# 操作・UI

スマートフォン向けの入力操作と UI フローを定義する。対応環境は [overview.md](./overview.md#対応環境) を参照。

---

## 対応デバイス

MVP では **スマートフォンのタッチ操作**（地図のパン／ピンチ、ドックからのドラッグ配置、仮配置中の向き調整）を想定する。

タブレット・PC ブラウザでの表示は将来対応とし、MVP では最適化しない。

---

## 操作・UI の詳細

関連 Issue: [#14](https://github.com/NUMaters/civileng-project/issues/14)

### 地図操作

- 1 本指ドラッグで地図を移動する
- ピンチでズームする
- 回転・傾斜操作は誤操作と端末負荷を検証し、MVP で有効にする範囲を決める
- カメラは画面中央の注視点が阿武隈川周辺から離れすぎないよう制限する（カメラ位置そのものはクランプしない。俯瞰時のガクガクを防ぐ）
- ピンチアウトで区間全体を見渡せるよう、ズーム上限は余裕を持たせる

### 施設配置

関連 Issue: [#96](https://github.com/NUMaters/civileng-project/issues/96)

1. 下部の建設ドックから施設カードをドラッグする（カード左のシーン風イラストは `apps/web/public/icons/structures/*.svg`）
2. **阿武隈川の河道または河岸（薄い青い帯）の上**へドロップして**仮配置（プレビュー）**する（市街地には置けない。この時点では予算を消費しない）
3. 仮配置の向きは、その時点のカメラ heading に合わせる。プレビュー中のみ**施設の手前に出る向きスライダー**、または地図上の左右ドラッグで調整する（向き矢印表示。角度表示・左右ボタンなし。地図ドラッグを離すと 5° スナップ）
4. **確定**は施設上の小さなチェック（✓）で行う（Enter でも可）。**キャンセル**は隣の ×（Esc でも可）。大きな確定バーや向きモーダルは出さない
5. **確定後は向きを変更できない**（タップ選択は可能だがスライダー／ドラッグ回転は出さない）
6. プレイ範囲外・河道外へのドロップは受け付けず、理由をトースト表示する（不正位置では仮配置も開始しない）
7. 予算不足など判定失敗時も理由を表示する
8. **地図上のタップ／クリックでは施設を配置しない**（誤設置防止。配置はドラッグ＆ドロップのみ）

配置判定は中心線 ± 約 75 m の河道＋河岸コリドー（`PLACEABLE_CORRIDOR_HALF_WIDTH_M`）を基本とする。帯内ではポインタ位置をそのまま採用し、中心線への強制スナップは行わない。市街地（氾濫原外側）は拒否する。水面ポリゴン（OSM relation/18504988）も河道判定の参考に使う。見た目の薄い青い帯が配置可能域、濃い水面は本川。古い Safari でも動くよう配置 ID 生成に `randomUUID` フォールバックを使う。

### HUD（一時）

マップ検証のため、ブランドヘッダー（CivilCraft）とミッションカードは一時非表示。予算表示・建設ドック・配置フィードバック用トーストのみ表示する。トーストは約 3.5 秒で自動的に消える。
