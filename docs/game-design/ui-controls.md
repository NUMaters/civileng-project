# 操作・UI

スマートフォン向けの入力操作と UI フローを定義する。対応環境は [overview.md](./overview.md#対応環境) を参照。

---

## 対応デバイス

MVP では **スマートフォンのタッチ操作**（地図のパン／ピンチ、ドックからのドラッグ配置、設置後の回転）を想定する。

タブレット・PC ブラウザでの表示は将来対応とし、MVP では最適化しない。

---

## 操作・UI の詳細

関連 Issue: [#14](https://github.com/NUMaters/civileng-project/issues/14)

### 地図操作

- 1 本指ドラッグで地図を移動する
- ピンチでズームする
- 回転・傾斜操作は誤操作と端末負荷を検証し、MVP で有効にする範囲を決める
- カメラは画面中央の注視点が阿武隈川周辺から離れすぎないよう制限する（カメラ位置そのものはクランプしない。俯瞰時のガクガクを防ぐ）
- ピンチアウトで区間全体を見渡せるよう、ズーム上限は余裕を持たせる

### 施設配置

1. 下部の建設ドックから施設カードをドラッグする
2. **阿武隈川の河道（画面上の青い帯）の上**へドロップして配置する
3. 設置時の向きは、その時点のカメラ heading に合わせる
4. 設置後、施設をドラッグすると円周方向に回転して向きを調整できる（タップで選択）
5. プレイ範囲外・河道外へのドロップは受け付けず、理由をトースト表示する
6. 予算不足など判定失敗時も理由を表示する
7. **地図上のタップ／クリックでは施設を配置しない**（誤設置防止。配置はドラッグ＆ドロップのみ）

河道判定は OpenStreetMap の阿武隈川水面ポリゴン（岸から約 18 m の余裕付き）への点包含を基本とし、ドロップずれは中心線から約 70 m 以内なら中心線上へスナップして受け付ける。見た目の青い帯は中心線コリドー。古い Safari でも動くよう配置 ID 生成に `randomUUID` フォールバックを使う。

### HUD（一時）

マップ検証のため、ブランドヘッダー（CivilCraft）とミッションカードは一時非表示。予算表示・建設ドック・配置フィードバック用トーストのみ表示する。トーストは約 3.5 秒で自動的に消える。
