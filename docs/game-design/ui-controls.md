# 操作・UI

スマートフォン向けの入力操作と UI フローを定義する。対応環境は [overview.md](./overview.md#対応環境) を参照。

---

## 画面フロー（ロビー）

1. **タイトル** — CivilCraft ブランド表示。タップでメニューへ
2. **メニュー** — シングル／マルチ選択（マルチは無効表示）。遊び方モーダル。読込完了後に「ゲームスタート」
3. **本編** — マップ・ドック・状況 HUD（準備 → 災害 → 結果）
4. **結果** — 「ゲームメニューへ戻る」でメニューに戻り、シングル選択→読込→再スタートできる

---

## 対応デバイス

MVP では **スマートフォンのタッチ操作**（地図のパン／ピンチ、ドックからの上方向ドラッグ配置、仮配置中の向き調整）を想定する。狭幅ではカメラ傾斜をオフにし、FloodHud は表示のみで地図操作を通す。仮配置中の ✓／×・向きスライダーはドックより前面に出し、ヒット領域は約 44px 以上とする。

タブレット・PC ブラウザでの表示は将来対応とし、MVP では最適化しない。

## 操作・UI の詳細

関連 Issue: [#14](https://github.com/NUMaters/civileng-project/issues/14)

### 地図操作

- 1 本指ドラッグで地図を移動する
- ピンチでズームする
- 回転・傾斜操作は誤操作と端末負荷を検証し、MVP で有効にする範囲を決める
- カメラは画面中央の注視点が阿武隈川周辺から離れすぎないよう制限する（カメラ位置そのものはクランプしない。俯瞰時のガクガクを防ぐ）
- ピンチアウトで区間全体を見渡せるよう、ズーム上限は余裕を持たせる

### 施設配置

関連 Issue: [#96](https://github.com/NUMaters/civileng-project/issues/96)

1. 下部の建設ドックから施設を**上方向へ**ドラッグする（カード列の横スクロールと区別するため、横移動が優勢なときはスクロール優先。カード左のシーン風イラストは `apps/web/public/icons/structures/*.svg`）
2. **川の配置帯（アンバー）**へドロップして**仮配置（プレビュー）**する（まちなかには置けない。この時点では予算を消費しない）
3. 仮配置の向きは、その時点のカメラ heading に合わせる。プレビュー中のみ**施設の手前に出る向きスライダー**で調整する（スライダーを動かしている最中もモデルと**影響圏**が同じ向きでライブ回転する。角度表示・左右ボタンなし）
4. 確定するまでは**地図上のドラッグ**または**矢印キー**で仮配置の位置を微調整できる（配置帯の内側のみ。域外へ離すと元の位置へ戻す）。向きスライダー操作中は**手を離す前から**施設モデルと影響圏が同じ向きでライブ回転する。影響圏の形は施設種別ごと（帯／楕円／扇）で、帯は**堤体長軸（向き+90°）**、楕円・扇は**施設正面**に追従する。ドックからドラッグ中・仮配置中も影響圏をプレビュー表示し、カバー状態（緑＝適所／黄＝範囲外／赤＝相性外）で狙いを示す（文言ヒントは出さない）。弱点マーカーはドラッグ中・仮配置中・確定配置があるときだけ表示する（未開始・未配置では出さない。数値の治水効果は確定後のみ）
5. **配置確定**は施設上の小さなチェック（✓）で行う（Enter でも可）。**キャンセル**は隣の ×（Esc でも可）。大きな確定バーや向きモーダルは出さない
6. **確定後は向き・位置を変更できない**（タップ選択は可能だがスライダー／移設は出さない）
7. プレイ範囲外・配置帯外へのドロップは受け付けず、理由をトースト表示する（不正位置では仮配置も開始しない）
8. 予算不足など判定失敗時も理由を表示する
9. **地図上のタップ／クリックでは施設を配置しない**（誤設置防止。配置はドラッグ＆ドロップのみ）

配置判定は中心線 ± 約 75 m の河道＋河岸コリドー（`PLACEABLE_CORRIDOR_HALF_WIDTH_M`）を基本とする。帯内ではポインタ位置をそのまま採用し、中心線への強制スナップは行わない。市街地（氾濫原外側）は拒否する。水面ポリゴン（OSM relation/18504988）も河道判定の参考に使う。見た目のアンバー帯が配置可能域、濃い水面は本川。浸水の水色は決壊地点付近のみに出し、河道沿いの広域水色帯は描かない。古い Safari でも動くよう配置 ID 生成に `randomUUID` フォールバックを使う。UI 文言は軍事調（作戦・防衛など）を避け、治水・配置寄りの表現に揃える。状況 HUD は水位・被害などの指標を中心にし、効果パラメータの細内訳は出さない。施設は弱点種別との相性（`hazardAffinity`）が重要で、合わない場所への設置は効果が薄いだけでなく流域を悪化させうる。同種の重ね置きは逓減し、適所の混成が必要。

### HUD（一時）

マップ検証のため、ブランドヘッダー（CivilCraft）とミッションカードは一時非表示。予算表示・建設ドック・配置フィードバック用トーストのみ表示する。トーストは短文・短時間（約 2.2〜2.8 秒）で、同じ文言の連投は抑え、出入りはフェード＋わずかな移動で行う。キャンセルや緊急予算付与など自明な操作では出さない。
