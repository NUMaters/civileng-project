# セッションフロー

1 プレイ全体の画面遷移とフェーズ進行を定義する。プレイ中ルールは [game-rules.md](./game-rules.md)、概要は [overview.md](./overview.md) を参照。

---

## フェーズの定義

| フェーズ | 位置づけ |
|---------|---------|
| **ロビー** | **本編開始前**。ゲーム操作方法の説明・ゲーム説明・名前設定・ルーム作成や参加・待機など（ソロ・マルチ共通） |
| **準備** | **ゲーム開始後**、災害が始まるまでの猶予時間 |
| **災害** | 大雨発生、水位上昇・浸水進行 |
| **結果** | 被害状況・被災度の表示、勝敗判定、評価・振り返り |

**約 180 秒（3 分）のプレイ時間**は準備・災害・結果のみを指し、**タイトル／メニュー（ロビー）は含まない**。各フェーズの秒数は `packages/game-data/rules/game-timing.json` で管理する（準備 60 秒・災害 90 秒・結果 30 秒。[game-rules.md](./game-rules.md) 参照）。

## 想定する流れ

### ソロプレイ

```
タイトル → メニュー（シングル選択・遊び方） → 読込 → ゲームスタート → 準備 → 災害 → 結果 → メニュー（再挑戦可）
```

| フェーズ | 概要 |
|---------|------|
| **ロビー** | 名前設定・ゲーム説明・操作方法の確認など（**ルームは作成しない**） |
| **準備** | ゲームデータの読み込み完了後、マップ確認・施設配置（建設開始） |
| **災害** | 大雨発生、水位上昇・浸水進行。追加施設の配置も可能 |
| **結果** | 被害状況・被災度の表示、勝敗判定、評価・振り返り |

### マルチプレイ

```
ロビー → 準備 → 災害 → 結果
```

| フェーズ | 概要 |
|---------|------|
| **ロビー** | 名前設定・ゲーム説明・ルームの作成・一覧からの参加・待機 |
| **準備** | ゲーム開始直前のデータ読み込み後、マップ確認・施設配置（建設開始） |
| **災害** | 大雨発生、水位上昇・浸水進行。追加施設の配置も可能 |
| **結果** | 被害状況・被災度の表示、勝敗判定（被災度がクリア閾値未満でクリア）、評価・振り返り |

- **ルーム作成者**がゲーム開始を行う（ロビー → 準備への遷移）
- **2 人以上**（最大 4 人）が揃ってから開始可能。1 人だけでは開始できない
- ゲームデータの読み込みは**開始直前**（準備フェーズ開始時）に行う

---

## ルーム参加（マルチプレイ）

- **誰でもルームを作成**できる
- 参加者は**作成済みルーム一覧から選択**して参加する
- **2 人から最大 4 人**まで。1 人だけではマルチを開始できない
- QR コードはゲームへのアクセスにのみ使用し、ルーム招待には使用しない
