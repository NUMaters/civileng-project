# Pull Request

GitHub 上では [.github/PULL_REQUEST_TEMPLATE.md](../../.github/PULL_REQUEST_TEMPLATE.md) が自動適用される。

## タイトル例

```
feat: 洪水シミュレーション追加
```

## テンプレート

詳細は [.github/PULL_REQUEST_TEMPLATE.md](../../.github/PULL_REQUEST_TEMPLATE.md) を参照。

主なセクション:

- 概要 / 関連 Issue（任意） / 変更種別
- 実装内容 / スコープ確認
- ドキュメント / テスト・品質
- 動作確認 / スクリーンショット
- レビュー観点 / 未完了（Draft 時）
- マージ後の作業

Issue との紐付けは必須ではない。機能追加や仕様変更など、追跡が必要な作業では Issue を作成して `Closes #` でリンクする。軽微な修正やレビュー指摘への即時対応など、Issue を切らない PR もよい。
