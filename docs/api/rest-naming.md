# REST API 命名

名詞で表現する。動詞は禁止。

例：

```
GET    /rooms
POST   /rooms
GET    /rooms/:id
DELETE /rooms/:id
```

禁止例:

```
/createRoom
/deleteRoom
/getRoom
```
